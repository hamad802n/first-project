# Project (Run Game)
## Overview

This is a run game , the player (user) should avoid the obstacles to win once the timer runs out if the player manages to hit one of the obstacles it gonna be game over.




## Technologies Used
 HTML
 CSS
 JavaScript

## User Stories
user should be able to win
user should be able to jump (arrow up key)
user shoudl be able to avoid the obstacles
user should be able to see the timer 
user should be able to hit play again if lost or won
